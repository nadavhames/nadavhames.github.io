# nadavhames.com

Personal site, served by GitHub Pages.

```bash
bun dev            # preview at http://localhost:8000 with live reload
bun run build      # render the HTML pages from content.ts
bun run format     # Prettier
```

- **Change text** in `content.ts`. Every page is generated from it; don't edit the `.html` files.
- **Deploy** by pushing to `master`.
- **Update the résumé** by replacing `Nadav-Hames-Resume.pdf`, or run **Actions → import resume**
  to pull it from FlowCV.
